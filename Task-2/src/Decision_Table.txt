COMPLEXITY SUMMARY
------------------
Problem 1 – BST:
- Insert/Search: average O(log n), worst O(n).
- Traversals: O(n).

Problem 2 – Hash Table:
- Insert/Search: average O(1), worst O(n) with long chains.
- HashMap lookup: average O(1).

Problem 3 – Graph:
- BFS: O(V + E).
- DFS: O(V + E).
- Topological sorting: O(V + E).
- Cycle detection using topological sorting: O(V + E).

Problem 4 – Sliding Window:
- Time: O(n).
- Extra space: O(1).

Problem 5 – Two Pointers:
- Time: O(n).
- Extra space: O(1).

V = number of vertices; E = number of edges; n = input size.
